# ShortLink 3.0 (Vue.js + FastAPI)

Лабораторна робота: Розробка Web-додатка засобами Javascript/VueJS.

## Технології:
- Frontend: Vue 3 (Vite), Vue Router, Axios, Bootstrap 5.
- Backend: Python, FastAPI, SQLAlchemy, SQLite.

## Запуск проєкту:
1. Запуск сервера: `uvicorn main:app --reload`
2. Запуск клієнта (в папці frontend): `npm run dev`
