# 🔗 ShortLink

Лабораторна робота з дисципліни "Веб-дизайн". Проєкт являє собою статичний адаптивний інтерфейс для сервісу скорочення URL-посилань.

## Демонстрація
Готовий сайт розгорнуто на GitHub Pages:
**https://valchyshensviatoslav.github.io/url-shortlink/**

## Технології
* **HTML5**
* **CSS3** **Bootstrap 5** (для швидкої розробки та адаптивності під мобільні пристрої)
* **JavaScript**

## Структура проєкту
1. `index.html` — Головна робоча сторінка з формою вводу для скорочення посилання.
2. `register.html` — Форма реєстрації нового користувача.
3. `login.html` — Форма аутентифікації.
4. `profile.html` — Особистий кабінет з таблицею історії посилань.
5. `about.html` — Сторінка з коротким описом додатку.
6. `app.js` — Реалізація функціональності додатку.
